# pi-web-usage-viewer

面向 pi-web 的用量与费用统计查看器，基于 Thomas Mustier 的 **@tmustier/pi-usage-extension** 独立改造。

## 功能

- 按今天、本周、上周、本月、最近 30 天、全部历史或自定义时间段汇总。
- 按服务商、模型统计费用、Token 和消息数。
- pi-web：在会话内显示 SVG 费用趋势、各模型费用排行和 Markdown Token 明细表，可点击放大、缩放和下载图片。
- 终端：保留图表、表格和分析交互面板，支持导出 CSV / JSON。
- 不修改 pi-web 源码，不启动独立网页或服务，不查询额度或调用模型。
- 读取本地 Pi 历史会话，缓存解析结果以加快后续查询。

## 使用

### pi-web

```text
/usage
/usage today
/usage thisWeek
/usage lastWeek
/usage thisMonth
/usage last30Days
/usage allTime
/usage 2026-11-01 2026-11-06
/usage 2026-11-01T08:30 2026-11-06T18:00
```

- 无参数时弹出标准 Pi 时间范围选择框，可选择预设范围或输入自定义起止日期；取消不会扫描会话或生成消息。
- 指定预设名或两项日期时直接生成报告。每次生成新的会话消息，不会覆盖旧报告。
- 折线图按后端本地日历日精确汇总并补零；超过约 93 天改按月聚合，跨度更大时合并多个月，限制图形大小。图中注明实际粒度。
- 模型排行显示前 12 名，其余合并；明细表最多显示费用最高的 100 行，并明确提示截断。
- 图表是静态 SVG，不支持悬停查看数值。短时间范围会直接标注费用。
- 报告通过 `sendMessage(..., { triggerTurn: false })` 发送，不启动模型回合；消息会保存在当前会话，并进入后续模型上下文，建议在专门的统计会话中使用。

### 终端

`/usage` 打开原有交互面板；`/usage 开始日期 结束日期` 默认打开 Custom 标签，仍可切换其他预设时间。预设名称参数仅用于 SVG 报告模式。

### 时间范围规则

- 所有时间范围使用**运行 Pi 后端的电脑所设置的本地时区**，不是浏览器时区，也不固定为中国时间。报告和 Custom 标签注明后端时区名称。
- 纯日期结束值包含结束日全天；带 `THH:mm` 的结束值不包含该时刻，即 `[开始, 结束)`。同一天查询可将两个日期写为相同值。
- 日期结束边界为下一天本地零点，夏令时切换日可能为 23 或 25 小时。不存在的本地时间会报错；回拨时重复出现的时间按 JavaScript Date 行为选择较早的一次。
- 自定义导出文件名含起止日期，分析 JSON 也记录范围及后端时区。自定义范围不展示与所选范围无关的“最近 7 天”趋势分析。
- 切换范围时从缓存的历史消息重新筛选，不会复用其他范围的汇总。非法日期、反向范围或错误参数会显示提示。

### 终端常用操作

| 按键 | 功能 |
| --- | --- |
| `Tab` / `←` / `→` | 切换时间范围 |
| `v` | 切换图表、表格和分析视图 |
| `↑` / `↓` | 选择服务商或图表系列 |
| `Enter` / `Space` | 展开模型明细或切换系列显示 |
| `m` / `g` / `c` | 切换图表指标、分组、累计模式 |
| `/` | 筛选表格中的服务商和模型 |
| `e` | 导出当前视图 |
| `q` / `Esc` | 关闭面板 |

## SVG 图表展示实验

`chart-probe.ts` 是独立测试扩展，与 `/usage` 的真实统计报告分离。加载后执行 `/usage-chart-test`，向当前会话发送带 `svg` 代码块的扩展消息，验证 pi-web 是否显示折线图，以及点击放大、缩放和下载是否可用。

- 只使用七天的模拟数据，不读取真实会话、不查询额度、不调用模型。
- 不修改 pi-web 源码，不启动独立网页或服务。
- 测试消息会保存到当前会话，且标准扩展消息会进入后续模型上下文；建议在测试会话中执行。
- 该测试扩展不在默认包入口中。可通过 `pi -e ./chart-probe.ts` 在终端加载；pi-web 使用正常的扩展加载机制，加载后执行 `/reload` 或重启会话。
- 示例图和真实统计报告均已由用户在 pi-web 中确认可显示，不提供图内悬停交互。

## 统计口径

费用来自本地 Pi 会话中持久化的 usage 数据，以美元显示，不等于订阅的实际账单，也不会查询服务商账单。未记录的费用无法追溯补算。趋势、排行与明细复用同一份去重后的统计；无法确定时间戳的记录只计入全部历史总额，不画入趋势图，并提示差额。

工具、压缩和分支摘要用量在有记录时计入统计，无法可靠归属模型的部分显示为 `Tools / summaries`，不增加助手消息数。Token 总量为输入、输出与缓存写入之和，缓存读取单独展示。

## 开发

```bash
npm ci
npm test
npm run check
```

测试使用临时会话文件，不读取真实会话或登录凭据。覆盖时间边界、夏令时、跨日聚合、冷热缓存、SVG / Markdown 转义、空数据、选择取消和失败处理。已在 Asia/Shanghai、America/Los_Angeles、Asia/Kathmandu 和 UTC 下运行。运行测试建议 Node.js 24+。
